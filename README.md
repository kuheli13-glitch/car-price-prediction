# Car Price Prediction

Predicts used car prices using supervised machine learning.

## What it does
Takes car features (brand, year, mileage, fuel type etc.) 
as input and predicts the market price using a regression model.

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Jupyter Notebook

## How to run
1. Clone the repo
2. Install dependencies: `pip install -r requirement.txt`
3. Open `Car_Price_Prediction.ipynb` in Jupyter

## Dataset
CarPrice_Assignment.csv containing features like car brand, 
engine size, horsepower and price.
